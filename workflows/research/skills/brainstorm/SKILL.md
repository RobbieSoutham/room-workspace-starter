# Brainstorm

Use for early-stage research ideation. Keep divergent generation separate from selection.

1. Restate the problem, constraints and intended contribution.
2. Generate distinct mechanisms or questions; label assumptions and speculative parts.
3. Search available literature for relevant prior work and competing explanations when novelty or feasibility matters.
4. For each candidate, state the observable prediction, a plausible falsifier, required data and main failure mode.
5. Compare options against importance, answerability, evidence access and ethical or practical constraints.

Return a compact candidate table and the unresolved questions. Do not call an idea novel without a documented search and comparison with prior work.
