# Research skill map

Read a skill when its task is needed; do not chain every skill into every job. Use the smallest set that covers the question and its risk.

## Question and planning

| Skill | Use it for |
|---|---|
| [research-question-development](../workflows/research/skills/research-question-development/SKILL.md) | Narrow a broad topic into a tractable question |
| [research-frame](../workflows/research/skills/research-frame/SKILL.md) | Record the question, contribution, falsifier and method before substantial work |
| [brainstorm](../workflows/research/skills/brainstorm/SKILL.md) | Generate and compare early research directions |
| [hypothesis-generation](../workflows/research/skills/hypothesis-generation/SKILL.md) | Produce falsifiable, literature-grounded hypotheses |
| [research-protocol](../workflows/research/skills/research-protocol/SKILL.md) | Specify a review, study or computational method |
| [premortem](../skills/premortem/SKILL.md) | Find plan-specific failure paths and tripwires |
| [adversarial-refinement](../skills/adversarial-refinement/SKILL.md) | Pressure-test a proposal or decision |
