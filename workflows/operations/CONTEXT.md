# Operations room

## Purpose

Maintain shared workspace tools, reliability and operating procedures.

## Boundaries

- Keep machine-specific settings and credentials outside this repository.
- Coordinate changes that affect every room; document the resulting shared rule in `PROTOCOLS.md` when appropriate.

## Canonical files

- Active operations work: `CURRENT.md`
- Durable operations knowledge: `knowledge/`
- Cross-room procedures: repository `PROTOCOLS.md`
