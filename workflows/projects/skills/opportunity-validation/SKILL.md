# Opportunity validation

Use before substantial time, money or implementation is committed to an uncertain opportunity.

1. State the target user or beneficiary, problem, proposed value and the decision this validation should inform.
2. List the riskiest assumptions, separating user need, feasibility, adoption, cost, rights and delivery constraints. Compare direct competitors with substitutes and current workarounds before proposing implementation.
3. Choose the smallest ethical, low-cost test that can distinguish between plausible outcomes; define success, failure and inconclusive results in advance.
4. Gather evidence from appropriate sources and preserve provenance, consent and privacy boundaries. Distinguish stated interest from observed behaviour.
5. Test pricing, trust and distribution as possible differentiators only after establishing that the user problem is real and important. Recommend proceed, revise, stop or gather one named missing signal. Record uncertainty; validation does not itself authorise spending or launch.
