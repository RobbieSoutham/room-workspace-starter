# Hypothesis generation

1. Define the phenomenon, outcome, unit and scope.
2. Identify established findings, contradictions and evidence gaps from traceable sources.
3. Generate distinct mechanisms, not only variations of one preferred explanation.
4. For each hypothesis, state predicted observations, a falsifier, identification needs and alternative explanations.
5. Rank by importance, testability, evidence access and risk of bias; label novelty as unverified until searched.

Return a scored set with links to supporting and conflicting evidence. Do not present a plausible mechanism as an empirical finding.
