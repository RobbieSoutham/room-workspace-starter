# Workflow catalogue

The catalogue is an index, not a status authority. Keep one concise row per room and per major project, and link to its current context/status and durable evidence. Use local, neutral names when adapting the example.

## Room register

| Room | Purpose | Agent/host binding | Context and current state | Boundary |
|---|---|---|---|---|
| `operations` | Shared tools, reliability, security, capacity, routing and procedures | Host-specific | `workflows/operations/CONTEXT.md`, `CURRENT.md` | Do not store personal credentials or live account state in public docs |
| `research` | Research questions, literature, methods, analysis and scholarly communication | Host-specific | `workflows/research/CONTEXT.md`, `CURRENT.md` | Claims and evidence stay in the research/project authority |
| `projects` | Portfolio intake, project coordination and delivery | Host-specific | `workflows/projects/CONTEXT.md`, `CURRENT.md` | Detailed project work lives in project repositories |

## Project register template

| Project | Owner room | State | Canonical location | Status/evidence | Next review |
|---|---|---|---|---|---|
| `<project>` | `<room>` | `active / paused / parked / closed / unresolved` | `projects/<name>/` or linked repository | Link to project status and decision evidence | `<date/event>` |

Use explicit statuses and define them locally. Directory presence, a dashboard tile or an old message does not establish that work is active. Keep dated decisions and distinguish an owner-reported status from an independently verified state. A registry points to evidence; it must not replace scientific or operational authorities.

## Candidate and promotion records

For workflow or project proposals, record whether the item is a design, trial, adopted default or retired approach. A successful component check does not establish end-to-end superiority. Do not infer that a newer proposal supersedes an older one; record the owner decision and evidence for promotion, replacement or retirement.

Avoid putting named personal projects, papers, collaborators, institutions, account routes or private status in this starter. Create local project records after copying the template.
