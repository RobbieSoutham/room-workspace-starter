# Research knowledge context

1. State the question and identify the relevant project, methods and topic indexes.
2. Search the index first; open only notes needed to answer the question.
3. Follow source links to primary papers for claim-bearing facts.
4. Distinguish note author interpretation, imported metadata and primary-source text.
5. Report stale notes, conflicting records and missing source links.

Return a compact context summary with links to the notes and original sources. A knowledge graph or note count does not establish truth or completeness.
