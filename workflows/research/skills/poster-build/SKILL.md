# Poster build

1. Confirm audience, venue size, viewing distance and required content.
2. Reduce the story to question, method, key evidence, interpretation and limitations.
3. Use a clear reading path and a small number of evidence-bearing figures.
4. Set type size for the physical poster, check contrast and provide descriptive labels.
5. Verify every number, citation, logo and conclusion against the source manuscript.

Return an editable poster and export with a content/source checklist. Do not imply generality beyond the study or use scale to conceal uncertainty.
