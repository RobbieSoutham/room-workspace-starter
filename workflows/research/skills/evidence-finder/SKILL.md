# Evidence finder

Use for quotes, claim checks and citation traceability.

1. Split the claim into factual components and identify the source expected to support each one.
2. Search permitted full text first; otherwise mark the actual scope searched (abstract, metadata or notes).
3. Capture a short exact passage with page, section, paragraph or stable character locator.
4. Separately judge support: direct, partial, contextual, contradictory or absent. Explain the match.
5. Reopen the source to verify quotation and locator before reporting.

Return claim, source identity, exact evidence, locator, support judgement and access scope. A text match confirms wording only; it does not by itself establish claim support.
