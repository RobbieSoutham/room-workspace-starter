# Paper scaffold

1. Confirm the question, audience, contribution and evidence already available.
2. Draft a one-sentence claim and test it against the results and closest prior work.
3. Create section headings with each section's purpose, required evidence and open gaps.
4. Map tables and figures to results; identify claims that cannot yet be made.
5. Add literature hooks with verified sources and use placeholders for unknowns.

Return an outline, claim-evidence map and missing-work list. Never write results, citations or novelty claims that have not been established.
