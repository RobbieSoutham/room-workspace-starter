# Documentation

These documents explain the room-based setup, its actual routing shape, the research workflow and room-local skills. The model catalogue and routing policy are maintained in `config/ai/`; these docs explain their rationale and current evidence. Keep names, account identities, private endpoints, credentials, balances and host-specific paths in local configuration. `model-evaluation-and-benchmarks.md` is the dated live-leaderboard record, while `model-access-and-offers.md` is the dated current promotions/free-tiers register.
