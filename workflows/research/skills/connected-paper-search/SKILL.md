# Connected paper search

Use when a topic search and known seed papers are available.

1. Record the question, seed identifiers, provider, query date and expansion limits.
2. Search backward references and forward citations from each seed; use recommendation services as a separate discovery channel.
3. Preserve each source-to-source relation and provider identifier. Do not merge records by title alone.
4. Deduplicate by stable identifiers, log ambiguous matches, then screen against predeclared criteria.
5. Report which branches were attempted, their yield, provider gaps and stopping rule.

Return a candidate set with provenance and a reproducible search log. Citation connectivity is a discovery signal, not a quality score or proof of coverage.
