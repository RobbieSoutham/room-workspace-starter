# Figure generation

1. State the figure's purpose and intended reader.
2. Choose a chart or diagram that matches the data type and comparison; avoid decorative encodings that imply unsupported magnitude or order.
3. Keep source data, code or editable diagram specification beside the export.
4. Label units, axes, denominators, uncertainty, missingness and data source where relevant.
5. Check contrast, text size at final output dimensions, colour-blind readability and consistency with the manuscript.
6. Compare the export with the source and verify every value and label.

Return editable source, export and caption with provenance. Never reconstruct or smooth away inconvenient observations without documenting the transformation.
