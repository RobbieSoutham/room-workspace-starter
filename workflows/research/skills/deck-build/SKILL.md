# Deck build

Use when research needs an oral or slide-based explanation.

1. Establish audience, time, purpose and desired action.
2. Define one defensible takeaway and a narrative sequence that earns it.
3. Map each slide to one job, one main point and its evidence; cite claims near the relevant content.
4. Choose a visual only when it clarifies data, mechanism or comparison. Keep uncertainty, sample and source visible.
5. Check pacing, legibility, contrast, accessible labels, references and consistency with the source manuscript.

Return an outline or editable deck, plus a short verification list. Never invent results or compress away a limitation that changes the interpretation.
