# Paper code discovery

1. Resolve the paper identity and inspect its official version, supplement and author or project pages.
2. Search trusted repositories using title, DOI, authors and distinctive method names.
3. Verify that a candidate repository is linked to the paper by an author or primary source.
4. Record repository URL, license, release or commit, dependencies, archived version and apparent data access conditions.
5. Distinguish advertised availability from an inspected or successfully reproduced artifact.

Return evidence links and status: not found, claimed, linked, inspected or reproduced. A public repository is not automatically licensed for reuse or reproducible.
