# Projects room

## Purpose

Coordinate products, business work and other projects that do not belong to another specialist room.

## Boundaries

- Give each project a clear owner and a current status source.
- Keep credentials, customer data and private business records in approved storage.

## Canonical files

- Active project priorities: `CURRENT.md`
- Durable project knowledge: `knowledge/`
- Shared workspace rules: repository `CLAUDE.md` and `SOURCE_OF_TRUTH.md`

## Room skills

- `project-intake` — clarify ownership, outcomes, constraints and records
- `opportunity-validation` — test an opportunity with proportionate evidence before investing heavily
- `delivery-planning` — turn an accepted project into bounded milestones and review points
- `launch-readiness` — check a release's operational, legal, privacy and support readiness

Global skills are indexed in repository `SKILLS.md`.
