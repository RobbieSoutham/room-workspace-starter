# Literature note intake

Use for lightweight intake when no richer reference-manager workflow is available.

1. Capture the source URL or file and identify the work using DOI or another stable identifier.
2. Check whether a record already exists before creating a duplicate.
3. Record title, authors, year, venue, abstract and access status with provenance.
4. Create a literature note only from text actually inspected; label abstract-only notes.
5. Link the note to the search or project that led to it and record any follow-up reading need.

Return a linked record and note. If a reference manager or local intake procedure is canonical, use it instead of maintaining a parallel catalogue.
