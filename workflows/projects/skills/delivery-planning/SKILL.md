# Delivery planning

Use after a project has an owner and a decision to proceed.

1. Restate the accepted outcome, scope, constraints and evidence that will demonstrate completion.
2. Break delivery into milestones that produce reviewable artefacts; assign one accountable owner and due/review point to each.
3. Map dependencies, external decisions, resource assumptions and risks. Identify the critical path and early warning signs.
4. Define acceptance checks, stop conditions and a route for handling scope changes.
5. Keep the plan in the project's canonical status location. Report changes against baseline; a plan is not proof that work is complete.
