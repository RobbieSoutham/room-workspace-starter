# Rooms

Rename, remove or add rooms to match the work. Keep each room's scope distinct and record any cross-room ownership here.

| Room | Purpose | Context |
|---|---|---|
| `operations` | Shared tools, reliability and workspace maintenance | `workflows/operations/CONTEXT.md` |
| `research` | Research questions, evidence and academic outputs | `workflows/research/CONTEXT.md` |
| `projects` | Product, business and other project work | `workflows/projects/CONTEXT.md` |

Route work by subject. Use a cross-room task only when it genuinely changes shared policy or spans multiple domains; name the affected rooms in the work record.
