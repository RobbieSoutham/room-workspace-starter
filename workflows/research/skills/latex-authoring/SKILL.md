# LaTeX authoring

1. Inspect the document structure, bibliography workflow, class file and build command before editing.
2. Make a narrow, source-grounded change; preserve labels, citation keys and custom commands unless a change is required.
3. Keep figures, tables and generated artifacts traceable to their source files.
4. Compile with the existing environment and inspect warnings, references and rendered pages.
5. Report unresolved citations, unavailable assets or compilation issues explicitly.

Return the revised source and build status. Do not hand-edit generated bibliography or build files as if they were canonical source.
