# Paper summary

1. Verify the paper's identity and record which version was read.
2. Extract question, design, data, methods, findings and limitations from the source.
3. Bind each important statement to a page, section, figure or table.
4. Separate reported results from reviewer interpretation and relevance to the current research question.
5. Record access scope and missing details; cross-check quotations and numerical values.

Return a short structured summary with source locators and follow-up questions. If only the abstract was inspected, label the note abstract-only.
