# Literature synthesis

Use when sources have already been identified and the task is to compare them. For searching and screening, use `evidence-led-review`.

1. Define the question, source set, inclusion boundaries and synthesis level. Check that source records and relevant methods are available.
2. Extract each source's question, context, method, result, limitations and relation to the synthesis question.
3. Group by substantive themes or differences in evidence; do not use a source-by-source list as a substitute for synthesis.
4. Compare convergence, disagreement and gaps. Consider whether apparent disagreement follows from different populations, definitions, measures or methods.
5. Tie each substantive statement to identifiable sources, distinguish evidence from interpretation, and state coverage limits. Do not treat absence in this source set as proof that no evidence exists.
